                Cada ponto é uma feature. Eixo X = média Corpus 1, eixo Y = média Corpus 2.
                Cor = tamanho do efeito d (azul → C2, laranja → C1). Linha pontilhada = igualdade.
              

              

            


            
            

              

                
              

              

                Como o scatter de médias, mas o tamanho da bolha codifica uma terceira dimensão.
              

              

            


            
            

              

                Cada ponto = um texto. Eixo X = feature (top-N por |d|), eixo Y = valor norm/1000. Cor = corpus. Clique
                em um ponto para abrir o texto.
              

              

            


            
            

              

                Textos dos dois corpora clusterizados juntos. A faixa lateral identifica o corpus de cada texto.
                Features e textos reordenados por clusterização hierárquica (ward).
              

              

            


          


          
          


            

              
            


            
            

              
              
            


            
            

              

                
                

                  Eixos normalizados por feature (0–max). Usar "Top N features" acima para controlar a quantidade de
                  eixos.
