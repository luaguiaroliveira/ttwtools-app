<Fuzzy Model-Based Control: An Efficient Framework to Control Nonlinear Systems>

A number of real-world systems such as power converters, biochemical reactors, cars, and aircraft can be mathematically modeled by a set of nonlinear differential equations usually derived from physical laws. For this reason, they are called nonlinear systems. Frequently, linear controllers are employed to control (or stabilize) them. However, these controllers can exhibit poor performance when a large operating range is required. In order to outperform linear control limitations, nonlinear techniques were proposed, but their design can be a hard task for applications involving complex nonlinear systems. This essay aims at discussing the advantages of employing fuzzy model-based control to stabilize nonlinear systems when compared to conventional linear/nonlinear techniques.

Most of control applications regard linear techniques. Designers usually prefer this class of controllers because of their long successful history in industrial applications. The design of linear controllers is performed concerning linearized models whose validity is restricted to the vicinity of a given operating point of the nonlinear system. Thus, when a large operating range is required, or a time-variant reference must be tracked, linear controllers can exhibit poor performance or, in extreme cases, lead the system to instability. In addition, if the model owns "hard nonlinearities", the linearization procedure cannot be applied. This motivated development of nonlinear techniques.

Nonlinear control techniques have been proposed to outperform linear control limitations, but many of them can be difficult to be designed for complex nonlinear systems. In classical nonlinear control techniques such as feedback linearization, this difficulty is avoided by nonlinearity cancellation which attempts to impose some predetermined dynamical behavior for the system. Other techniques like passivity-based control try to respect the system’s structure and incorporate it into control design. However, passivity-based methods require solving partial differential equations, which also introduces difficulties to design.

In the last three decades, fuzzy model-based control has provided a suitable compromise between effectiveness and design complexity. The main feature of this nonlinear technique is related to the ability of fuzzy models describe nonlinear dynamics by blending simple linear subsystems. This local linearity of fuzzy models allows fuzzy controllers to be designed using Linear Matrix Inequalities, a convex optimization tool that can be efficiently solved by existing software. Another advantage of fuzzy control is that the nonlinearity information is introduced into control scheme, thus respecting the system’s structure.

In general, the control design for nonlinear systems is not a simple task. On one hand, if linear control is employed, the system's performance can be deteriorated. On the other hand, designing nonlinear controllers may be difficult since it may require solving hard equations, which even can have multiple solutions. Fuzzy model-based control offers the possibility of design nonlinear controllers simply solving a convex optimization problem. Therefore, fuzzy control can be viewed as a promising alternative to stabilize nonlinear systems, since it catches the good features of both linear and nonlinear classical techniques.
