<Code in School>

The Brazilian system of education is old and inefficient. Technology and society has evolved but the method of teach has not changed. Almost none professor stimulate students to think, to be creative, to use logic. The technology, like tablets and computers, is a wonderful solution to that issue. But the solution is not just to teach how to use computers in class, because children already have a great familiarity with interacting with new technologies, what is missing for them is the capability of being creative and to express themselves using those technologies. To that end, schools should teach how to code, and how students can use that to express their own idea.
        
Children have an incredible ability to not fear being wrong, if they do not know how to do something they will give a try no matter if they are doing it right or incorrectly. That is a wonderful thing about them, not because be mistaken is good, but because if you are afraid of being wrong, you will never come up with anything original. However in the actual education systems commit a mistake is the worst thing a student can do. In other words people have being educated out of their creative capabilities, making adults that are fright of being wrong.

Therefore teach to code in school is necessary. Te ability to code would not only allow them to be creative, but also would provide the skill of creation. Develop something, like a code, it is a really hard task, because it starts only with an idea and then it is necessary to turn a thought in a functionally project. In order to build the project, it is essential to reason systematically, by take complex ideas and break them down in to simpler parts, which already are known how to do it. In others words the children will be able to give live to their ideas and fantasies. 

And that is only one of the amazing things that you learn when you are starting to code. It also teaches firstly how to be persistent, by trying to find and solve bugs in your code when it is not working perfectly. And secondly how to work collaboratively when the project is being developed by more than one person. Even saying all that, the most amazing apart is that the school can also use the codification to teach other things like mathematics and physics by asking them to develop something correlated to those subjects.

In conclusion, learn to code brings a lot of benefits, and this should be done in the childhood because after that they will learn more efficiently and quickly. Above all the children will want to learn to code to have fun. Some people think that it is not worth because they are not going to use code in life, but kids do not learn how to read and write to become a professional writer, so they can learn how to code and not turn into a computer scientist. And there is no damage by learning it.
